# 🌌 Modern Login Page (HTML + CSS)

A sleek, modern **login page** built with pure **HTML & CSS** featuring:
- ✨ Glassmorphism card design  
- 🎨 Floating neon blobs + grain background  
- 🖱️ Hover & focus micro-interactions  
- 🔐 Password show/hide toggle  
- 🌐 Social login demo buttons (Google, GitHub)  
- 📱 Fully responsive
